# 64times

## Introduction

64times is a project bringing all new textures for BiomesOPlenty's additions to the game.  The goal is to create a cohesive and visually appealing texture pack that 
enhances the player's experience in the game.  Trees have been recreated as realistic as possible, and the new blocks have been designed to fit seamlessly into the existing 
Minecraft aesthetic.  The textures are created at a resolution of 64x64 pixels (some higher), providing a higher level of detail compared to the default textures.
