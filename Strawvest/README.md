# Strawvest

**Strawvest** is a Fabric mod that expands wheat and straw into useful agricultural, storage, decorative, and building materials.

Mature wheat produces straw that can be processed into bales, animal bedding, storage blocks, and thatch construction pieces.

## Features

### Straw and Agricultural Storage

- Wheat Straw drops from mature wheat
- Wheat Straw Bale
- Wheat Straw Bale Half
- Stackable half-bale system
- Sack of Wheat
- Reversible wheat and straw storage recipes
- Directional wheat sack placement

### Animal Bedding

- Placeable Straw Bedding for barns, stables, pens, and animal areas

### Thatch Construction

- Thatch Block
- Thatch Stairs
- Directional Thatch Slabs
- Top, bottom, and double slab variants
- Waterloggable slabs
- Consistent straw direction across connected slab pieces

## Compatibility

Strawvest includes optional compatibility with **Farmer's Delight**.

When Farmer's Delight is installed, its straw item is used automatically. Strawvest also includes its own fallback straw item so the mod can be used independently.

## Requirements

- Minecraft 26.1.2
- Fabric Loader
- Fabric API

## Installation

1. Install Fabric Loader for the supported Minecraft version.
2. Install Fabric API.
3. Place the Strawvest `.jar` file in your Minecraft `mods` folder.
4. Launch Minecraft using the Fabric profile.
