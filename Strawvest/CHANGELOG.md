# Changelog

## v1.1.0

### Added in v1.1

- Thatch Block
- Thatch Stairs
- Directional Thatch Slabs
- Top, bottom, and double Thatch Slab variants
- Waterlogging support for Thatch Slabs

### Fixed

- Thatch Slabs now retain their original direction when combined into a double slab
- Corrected texture alignment for stacked Thatch Slabs

## v1.0.0

### Added in v1.0

- Wheat Straw drops from mature wheat
- Farmer's Delight straw compatibility
- Wheat Straw Bale
- Wheat Straw Bale Half
- Stackable half-bale system
- Sack of Wheat
- Straw Bedding
- Reversible wheat and straw storage recipes
- Directional wheat sack placement
- Proper block drops, particles, and display transforms.
